WoW Vanilla Theme

This is an unofficial fan-made theme. It is not affiliated with, endorsed by or sponsored by Blizzard Entertainment.
World of Warcraft and Warcraft are trademarks or registered trademarks of Blizzard Entertainment, Inc.

The theme contains no files from the game. Every icon, texture and placeholder in it was drawn for this theme
(the sources are in the repository under src/WoWVanillaTheme/art) and is released under the repository's MIT license.
The colors and proportions follow the game's interface as it can be observed; the game's textures are not reproduced.

The client's UI font (Friz Quadrata TT) is a commercial font and is not included. The theme names it first in its
font list, so a machine that has it installed uses it; other machines fall back to Constantia, Palatino Linotype or
Georgia.

The XAML files start from Playnite's Default theme (MIT); see LICENSE-Playnite.txt.
