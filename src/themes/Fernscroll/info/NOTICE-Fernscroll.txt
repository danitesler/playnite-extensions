Fernscroll is an unofficial, fan-made Playnite Desktop theme inspired by the menu interface and storybook art direction of Snufkin: Melody of Moominvalley.

It is not affiliated with, endorsed by or sponsored by Hyper Games AS, Raw Fury AB, Moomin Characters Oy Ltd, or any rights holder of Snufkin: Melody of Moominvalley. All names and trademarks belong to their respective owners and appear only to identify the inspiration.

This package contains no game art, logo, font, character illustration, or screen capture from the game. Colors were sampled from public UI captures; the brand mark (a botanical fern-scroll spiral cradling a musical reed-note and star), scroll flourishes, swallowtail ribbons, dark plum quest cards, and texture masks were drawn or generated specifically for this theme.

Display headings and buttons use Pathway Gothic One (The Pathway Gothic Project Authors; shipped unmodified due to Reserved Font Name 'Pathway'), body text uses Barlow Semi Condensed (The Barlow Project Authors), and handwritten notes use Patrick Hand (Patrick Wagesreiter). All bundled font files and their SIL Open Font License 1.1 texts are in the theme's Typography folder and info/LICENSE-*.txt.

Icons are from Lucide (ISC License); see LICENSE-lucide.txt. XAML files start from Playnite's Default theme (MIT); see LICENSE-Playnite.txt.
