Bliss XP — Unofficial Playnite Desktop Theme

Bliss XP is an unofficial, fan-made Playnite Desktop theme inspired by the
Windows XP Luna Blue visual style (2001). It is not affiliated with, endorsed
by, or sponsored by Microsoft Corporation.

All vector marks, layouts, CSS tokens, XAML templates, and XP-style PNG icons
in this theme are original clean-room works created specifically for Playnite.
No copyrighted Windows bitmaps, DLL resources, or official Microsoft logos or
trademarks are included.
