# Bliss XP — theme notes

## What this is

Unofficial Playnite **Desktop** theme (`ThemeApiVersion` 2.9.0) inspired by **Windows XP Luna Blue** (`luna.msstyles`, 2001). Light theme with glossy Royal Blue chrome, Grass Green Start/Play accents, warm `#ECE9D8` beige controls with `#F8B330` Luna Orange hover rims, periwinkle `#D6DFF7` Explorer Common Tasks metadata cards, and full-color 32-bit XP-style PNG menu icons (`art/icons.py`).

Shared anatomy: **`../AGENTS.md`**. Loading rules and build checks: **`docs/themes/reference.md`**.

## Sources

Measurements and iconography rules: [`RESEARCH.md`](RESEARCH.md). Creative brief and levers: [`BRIEF.md`](BRIEF.md). Notice: [`info/NOTICE-BlissXp.txt`](info/NOTICE-BlissXp.txt).

## Tokens

`src/tokens.css` defines the Luna Blue palette (`--xp-*`), mapped in `src/Constants.template.xaml` to Playnite keys, shared vocabulary keys, and `LocalXp*` glossy gradients. `GameBannerTintBrush` uses `--xp-blue-dark` (`#1941A5`, deep Luna Royal Blue). `RunningIndicatorBrush` uses `--xp-run` (`#0E8A9E`, XP System-Tray Teal-Cyan). Light-theme window art flips unselected text to `WindowArtForegroundBrush` (`#FFFFFF`).

## Shell

- **Sidebar (`Views/Sidebar.xaml`)**: 44px glossy Luna Royal Blue vertical taskbar rail (`LocalXpRailBrush`) closed by `#00138C`, crowned by the `44×48` Grass Green Start `PART_ElemMainMenu` hosting `LocalBlissXpMenuMarkTemplate` (Bliss Hilltop-Window mark: sun rises and Luna Orange rim warms on hover; foreground hill and halo breathe slowly while the menu is open).
- **Top panel (`Views/TopPanel.xaml`)**: 48px glossy Luna Royal Blue bar (`LocalXpTitleBarBrush`) with `PART_TextMainSearch` (`248px`), `PART_ToggleFilter` (`8×8` gold circular pip, zero text), sorting-first `PART_PanelMainItems`, icon-only view switches, `12px` segmented green `PART_ProgressGlobal`, and glossy blue/coral-red `MainWindowButton` captions (`108px` clearance).
- **Menus (`ContextMenu.xaml`, `Menu.xaml`, `ComboBox.xaml`)**: `LocalBlissXpMenuBoardTemplate` (`#FFFFFF` card, `6px` glossy Royal Blue left spine with `14px` Luna Orange top cap), `30px` rows with `#316AC5` highlight + `3px` orange pip, 24 full-color 32-bit XP-style PNG icons (`Images/WinXP/*.png`), coral-red `Alt+Q` Exit, and green checkmarks.

## Components

- Both overviews are generated by `node src/themes/BlissXp/art/gen-overviews.mjs` (which runs `scripts/game-page-breakpoints.mjs` for `GameDetailsPanePosition` `Left` / `Center` / `Stretch` / `Right` and 900+/560+/<560 breakpoints).
- `PlayButton.xaml`: Grass Green Start pill (`Height="40"`, `MinWidth="164"`) with Luna Orange hover glow and `RunningActionIndicator` (`#0E8A9E` launching sweep + running idle pulse + `LOCCancelLabel` hover on `RelativeSource Self`).
- `GridViewItemTemplate.xaml`: `50×50` glossy green Play & Luna blue Info orb `GridTileButton`s.
- `StandardWindowStyle.xaml` + `TreeView.xaml`: `40px` glossy Royal Blue dialog title band with `LocalBlissXpBrandMarkTemplate` and `244px` `TreeView` section list.
