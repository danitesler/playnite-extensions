Frozen Throne: notices

This is an unofficial fan theme. It is not affiliated with, endorsed by or sponsored by Blizzard Entertainment.
"Warcraft", "Warcraft III" and "The Frozen Throne" and related names and marks belong to Blizzard Entertainment; they are
mentioned only to say what the look of this theme takes inspiration from.

No Blizzard artwork, logos, fonts, sounds or game files are included in this theme or were used to make it. The text
colors, font names and control proportions were read from publicly mirrored Frame Definition (FDF) text files and
written out as numbers; the stone, ice and background colors are estimates, because the game draws them with textures.
No file from the game is shipped.

The icons in Media.xaml and the add-on tile icon (source: art/mark.svg in the repository) are original artwork made for
this theme, released under the repository's MIT license (LICENSE).

The theme bundles no fonts. It asks for Friz Quadrata TT when it is installed, then Palatino Linotype, Book Antiqua and
Georgia, which ship with Windows.

The Playnite Default theme files this theme starts from are MIT licensed: see LICENSE-Playnite.txt.
