# Gilded Rift — implementation brief and handoff

Unofficial League of Legends / Wild Rift inspired theme. **This file is the working contract for whoever writes or finishes the XAML.** The visual spec is the two rendered previews (`art/screenshot-details.png`, `art/screenshot-settings.png`) and their sources (`art/preview-*.html`: exact sizes, colours as `var(--gr-*)`), plus `BRIEF.md` (moments, motion), `RESEARCH.md` (sources) and `src/tokens.css` / `src/Constants.template.xaml` (every colour role is already mapped; do not add colours, add roles only through the shared catalog).

## State at handoff

All 53 XAML overlays are written (four parallel passes, one per group in the Ownership table, each started from Gumshoe's structure and restyled) and `python3 -I art/check-static.py` reports 0 errors and 3 warnings (one `#00000000` gradient stop each in `Library.xaml` and the two generated overviews, kept on purpose). The previews, tokens, constants, sprites, font, mark, tile icon, manifests, README and root README row are done. **Nobody has looked at any of it in Playnite.** Checks the four authors asked Windows to make, on top of the list below:

- Group A: `ChamferTemplate` `Tag` binding and fallback; the `BlurEffect` rectangles in `GlowFrameTemplate`, `RingGlowTemplate`, `SelectionBarTemplate`; the check box tick draw-in; the `EmptyGameTemplate` idle loop and ring seams; the `WingsTemplate` Viewbox stretch; hairline seams on the Button, ToggleButton and RepeatButton cut corners at 125% and 150% scaling; the default Button bloom; slider thumb halo and `Width == 41` scaling.
- Group B: `TopPanelLayout`, `SearchGlyph`, `SearchClear`, `GridDetailsPanelWidth` tests; notch and keystone overflow (negative margins); the Canvas separator column; an add-on sidebar icon is visible; the Expander gem on Playnite group headers; `TabStripPlacement` Left in the edit dialog; Statistics GroupBox wrapping.
- Group C: `RunningLabelOverlap` (size the 56px reserved strip from `NeedRight`); the gem ping is not clipped in 32px list rows; the wings Canvas bindings and a narrow dialog; cover hover marks with a small `ItemSpacingMargin`; hover colour of the name text; hover and focus on chips.
- Group D: bloom and shine strength on Play; label contrast at the worst frame (`RunningMotionFrames`); the 36px gem room (`RunningLabelOverlap`); the `TextBlockGameScore` pill tint; the icon clip; Cinzel `LineHeight` 40 and the empty-state text offset; layout, close-button, breakpoint, Steam and running regression tests.

## Environment limits (why this is "unvalidated")

The session that wrote this ran on Linux with Node and Python only: no PowerShell, .NET or WPF, and Playnite must never run there. So **nothing here has been built, validated by `validate-extension.ps1`, loaded in Playnite or covered by `tests/wpf`**. `art/check-static.py` catches text-visible mistakes only (XML well-formedness, missing files, unresolved resource keys, literal colours). Everything in "Windows follow-up" below still has to be run on Windows.

## Source of structure

Playnite's Default files are not in this repo. Every XAML file here is **structurally derived from the Gumshoe theme's equivalent file** (`src/themes/Gumshoe/src/...`, the newest tree, validated there): keep its `PART_*` names, bindings, triggers, Steam gate, breakpoints, empty-state, close-button and running-indicator mechanics, then **restyle everything visual in Gilded Rift's language**. Never carry over Gumshoe visuals or names (paper, tape, bookmark, curtain, sprocket, smudge, price tag, chalk, felt, Anton, Patrick Hand, `gs-*`). Read the matching rule in `docs/themes/*.md` and `src/themes/AGENTS.md` before editing a file; the rules there beat this file.

## Colour rules

- Gold family = chrome, selection, hover, focus. **Hextech teal (`RunningIndicatorBrush`, `LinkBrush`, `ProgressBarForegroundBrush`, the notification count) is the live colour**: running or launching game, progress, links, the count badge. Never selection, hover, Play or the filter mark.
- Running indicator: teal frame (1px, `RunningIndicatorBrush`) + wash (teal at 10-35%, strongest at the left) + a 2px foot line + a diamond-ring "gem" mark (18px rotated square ring with an inner solid diamond) at the row's right end in a reserved strip with `RunningMarkPlate`. Launching: a 1.6s teal sweep band crossing the shape + the foot line filling + the gem pulsing; running: frame breathes 0.7 to 1 on a 3.2s cycle and the gem idles. Play cell: the plate fills with `RunningIndicatorBrush`, a `ScrimBrush` copy darkens it so the label holds 4.5:1; hover shows Cancel only on the button itself. Read `.agents/skills/playnite-theme-dev/SKILL.md` and `docs/themes/running-motion.md`.
- `GameBannerTintBrush` = `gr-navy` (set in Constants). Light-theme text flip does not apply (dark theme).

## Motion

Fast 120 ms, base 200 ms, slow 360 ms. `CubicEase` EaseOut for entrances and fades, EaseIn for exits, no overshoot. Entrances rise 6px with a fade; stagger 60 ms. Named storyboards are removed on exit; never a `RenderTransform` from a `Style` trigger on elements Playnite may recycle (see `docs/themes/reference.md` -> Builds).

## Shared template contract (Common.xaml, owner of the keys: foundation group)

Every template is a `ControlTemplate TargetType="Control"` used on a plain `Control`, `IsHitTestVisible="False"`, no wide desired size (Statistics cards stay compact: fixed pieces <= 56px, the rest stretches). Sprites in `src/Images/fx/` (`rays.png`, `glow.png`, `spark.png`) are white masks used as `OpacityMask` on a `Rectangle` filled with a host brush; reference them as `{ThemeFile 'Images/fx/<name>.png'}`. The contract table at the head of `Common.xaml` is authoritative once written.

## Windows follow-up (nobody has run any of this)

1. `pwsh scripts/validate-extension.ps1 -Extension gildedrift` and fix every error it reports; read the advisories (`layout`, `settings chrome`, preview colour drift).
2. `pwsh scripts/build-theme.ps1 -Extension gildedrift -Launch`; if Playnite falls back to Default, read `playnite.log` for the XAML error.
3. `pwsh -STA -File tests/wpf/<name>.ps1 -Keys gildedrift` for: `DetailsViewLayoutRegressionTests`, `GridOverviewLayoutRegressionTests`, `SidePanelCloseButtonRegressionTests`, `GamePageBreakpointsRegressionTests`, `GridDetailsPanelWidthRegressionTests`, `TopPanelLayoutRegressionTests`, `SearchGlyphRegressionTests`, `SearchClearRegressionTests`, `SteamScreenshotsRegressionTests`, `RunningIndicatorRegressionTests`, `RunningLabelOverlapRegressionTests`, and `RunningMotionFrames` (read `gildedrift-motion.png`).
4. `node scripts/generate-readmes.mjs` then `npm run check:readmes`; `pwsh scripts/validate-extension.ps1 -Extension gildedrift -Mode Package`.
5. Hand checks from `src/themes/AGENTS.md` -> Build and try, plus: empty page in both views, tiny/zero/default banner heights, ThemeModifier palette and Edit-constants recolouring, Statistics GroupBox wrapping, a launching and a running game.
6. Re-render the previews after any token change: `node scripts/render-theme-preview.mjs src/themes/GildedRift/art/preview-details.html src/themes/GildedRift/art/screenshot-details.png` (same for settings).
