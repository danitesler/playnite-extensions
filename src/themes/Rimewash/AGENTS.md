# Rimewash — theme notes

## What this is

Playnite **Desktop** theme (`ThemeApiVersion` 2.9.0), key `rimewash`, folder `Rimewash`, a **light** theme with no dark variant, inspired by the menu screens of *Child of Light* (Ubisoft Montréal, 2014): a pale blue-grey watercolour wash, torn white "snow" plates on a soft blue shadow, slate slots and buttons, orange values, a dotted pencil rule under every serif title, and a white dry-brush swipe plus a golden chevron cursor on whatever is selected.

**Unofficial fan theme**: not affiliated with, endorsed by or sponsored by Ubisoft or the game's developers. "Rimewash" is its own name. No game asset, logo or font is shipped: the mark (`art/mark.py`) is a hoarfrost crystal in a wobbled ring, every sprite is generated by `art/sprites.py` from noise, icons are hand-drawn in `src/Media.xaml`, colours are sampled values in `src/tokens.css`. See `info/NOTICE-Rimewash.txt`.

Shared anatomy (file map, shell rules, game page skeleton, metadata pane, build and first-run checks): **`../AGENTS.md`**. Loading rules and build checks: **`docs/themes/reference.md`**.

## ThemeModifier

Keep the ThemeModifier Edit constants list focused on main backgrounds, button fills and text, selection, and inputs. Include existing sidebar and panel surface brushes through the shared catalog. When panels share a brush or are transparent, use the existing background control. Keep the existing layout controls. Use the shared opt-ins in scripts/data/theme-keys.json and let the build generate thememodifier.yaml. Hover, pressed, and decorative colors stay in the theme. The accent picker lives in the Editor tab.

## Sprites (`src/Images/fx`, `art/sprites.py`)

White alpha masks at 2 px per DIP (PNG 192 dpi), generated with a fixed seed (`python art/sprites.py` from the theme folder; `art/fx-sheet.png` is the review sheet). `Common.xaml` turns them into templates; every one is filled with a theme brush through an `OpacityMask`, so ThemeModifier recolours them.

| Sprite | Cells (DIP) | Template |
|--------|-------------|----------|
| `plate-snow.png` | 9-slice 24 / 64 / 24 | `SnowPlateTemplate` (game page sheet, metadata card, GroupBox) |
| `plate-shadow.png` | 9-slice 40 / 32 / 40 | `SnowShadowTemplate` |
| `plate-chip.png` | 9-slice 12 / 16 / 12 | `ChipPlateTemplate` (metadata chips, tab chips) |
| `swipe.png` | 3-slice caps 40, body 32, height 44 | `SwipeTemplate`, `SwipeCompactTemplate` (rows, tree, rail, Play) |
| `chevron.png`, `chevron-glow.png` | 28x36 / 56x64 | `ChevronTemplate`, `ChevronGlowTemplate` |
| `pencil-rule.png` | tile 32x3 | `DividerTemplate` |
| `cloud.png`, `vignette.png`, `roots.png` | tile 256 / stretched / 120x260 | `CloudTemplate`, `VignetteTemplate`, `RootsTemplate` (library wash, empty page) |
| `wisp.png`, `blob.png`, `ring.png`, `crystal.png`, `mote.png`, `wisp-tail.png` | 48 / 40 / 32 / 96 | `WispTemplate`, `BlobTemplate`, `RingTemplate`, `CrystalTemplate` |

The 9-slice plates keep a centre underlay inset 9 so cell seams never show. No `DropShadowEffect` anywhere. The banner has no `OpacityMask` (repo rule): it fades into the sheet through a plain gradient to `SheetSwatch`, starting from a literal transparent frost (`#00F0F3F5`) so the fade does not pass through grey (it does not follow ThemeModifier edits of `GameOverviewBackgroundBrush` at its start stop).

## Game page

Generated by `art/gen-overviews.mjs` (one field table; edit the generator, then `node art/gen-overviews.mjs src` from the theme folder, which applies the repo's breakpoints). The whole page is a torn snow sheet on a soft shadow (`SheetLayer`; collapsed while game art is behind the window); the banner sits inside it with rounded top corners (two sheet-coloured cut-outs, no mask) and fades to the sheet colour by the title row (details: 30% to 64% of the banner height, grid: 30% to 54%), so the ink title is never on art; title in the serif at `FontSizeLargest` with Play, More and Edit beside it (no rule under the header); screenshots, description and notes left under serif headings with pencil rules; every metadata field in the right-hand inventory card (snow plate, 1px pencil hairlines between the six groups, chips are torn plates with a gold dot, play time and install size in the orange `ValueAccentBrush`). While game art is behind the window the sheet is gone and title, headings, description and notes switch to `WindowArtForegroundBrush`.

Empty state (no game selected): the mark breathing (Opacity only, only while it shows) over a soft blob, `LOCErrorNoGameSelected` in the serif under a pencil rule, pencil roots in the corner. The Settings window and every dialog use the same title band.

## Previews

`art/preview-details.html` and `art/preview-settings.html` are hand-written HTML replicas with colours as `var(--rw-*)`, sprites loaded from `../src/Images/fx` through `-webkit-mask-box-image` / `mask`. Motifs drawn: the slate rail with the snow-disc mark and the swipe plus chevron on the current item, the frost top bar closed by the pencil rule, swipe rows (one hovered, one selected with the chevron), the torn snow sheet on its shadow, the serif title with the Play plate in its hovered end state (white swipe, chevron and glow; the animation itself only runs in Playnite), screenshot slots, the inventory card with chips and pencil hairlines, the settings tree with the swipe and chevron, the serif title band with the ghosted mark, the L1 chip tab, the green tick, the gold node slider and the WAIT / CAST bar. Stand-in fonts: Constantia drawn with Gelasio (`scripts/data/fonts.json`); Jost is bundled and drawn as itself. The previews' game art and cover thumbnails are CSS drawings; score numbers are plain coloured text like `TextBlockGameScore`.

## Deviations

- Menu icons Playnite copies (`AddGameIcon`, ...) keep Playnite's icofont glyphs, recoloured by the palette; the rest of the icons are the theme's own hand-drawn strokes.
- Group dividers in the metadata card are solid 1px hairlines (the generator's group border), not the dotted pencil rule.
- Popups cannot cast shadows or show sprites (layered windows), so menus and dropdowns are plain snow sheets with a pencil edge.
- The game's painted icons (sword, wolf-head shield, boot, hourglass) have no Playnite counterpart and are not drawn.
- The Play label while launching reaches 4.33:1 at its worst frame (4.66:1 while running), under 4.5:1 for 15px Medium text; it passes the validator's large-text floor of 3:1. Darken `RunningBreath` further if it needs to clear 4.5:1.
- Motion is inferred from stills (RESEARCH.md); timings are this theme's own (fast 110ms, base 200ms, slow 380ms, `CubicEase` EaseOut).
- `HtmlTextView` (game descriptions) resolves installed fonts only, so the bundled Jost falls back there to Segoe UI.
