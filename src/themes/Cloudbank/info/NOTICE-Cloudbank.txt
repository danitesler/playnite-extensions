Cloudbank

This is an unofficial fan-made theme, inspired by the interface of Transistor. It is not affiliated with, endorsed by or sponsored by Supergiant Games.
Transistor is a trademark of Supergiant Games, LLC.

The theme contains no files from the game. Its mark, the corner brackets, the section bars and its layout were drawn for this theme; the icons are Phosphor (MIT, LICENSE-phosphor.txt).
Colors follow the game's interface as it can be observed in public screenshots; the game's art, function icons and logo are not reproduced.

Headings use Sora (by Jonathan Barnbrook and Julián Moncada), an open font bundled with the theme as a stand-in for Raleway. Body text uses Ubuntu when installed, otherwise Segoe UI. The font files and their license (SIL Open Font License 1.1, OFL.txt) are in the theme's Typography folder.

The XAML files start from Playnite's Default theme (MIT); see LICENSE-Playnite.txt.
