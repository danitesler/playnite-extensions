# Brushlight: creative brief

Mode: **Showcase** (a game). Dark only. Notes in `RESEARCH.md`; the reviewed previews are the real spec.

- **Lens (picked):** (c) Title / Pause menu: the camp menus (Character, Inventory, Merchant, Settings) with their tapered charcoal plates, broken dry-brush rims, plum selection and cream Roman capitals, plus the combat command stroke as the one loud moment (Play). Dropped (a) Diegetic: the expedition journals are only shown as text pages in game and would make another parchment theme. Dropped (b) HUD: the combat HUD is a few portraits and floating cards over 3D scenes; there is no persistent frame to carry the shell. Freshest against the last five (Tatterspire torn slate paper, Studlock LEGO plastic, Vice Dusk neon plum gradients, Cropmark comic Bristol board, Runeskald frost silver tablets): none uses arrow-notched plates with chalky brush rims, a plum fill selection or Roman inscriptional caps over a near-black smoke.
- **Source DNA:** 1. **Tapered plates with a broken white brush rim** -> rows, tabs, buttons, chips, search, combo boxes, the menu highlight. 2. **Plum selection on charcoal** -> selected tab, tree section, details row, view switch, default button. 3. **Cream Roman capitals with tall initials** (Cinzel) -> page titles, game title, section heads, title band; white old-style body (Palatino Linotype); Oswald numerals for scores, levels and counts. 4. **Hairline with a crossing tick** -> metadata group breaks, top bar foot, menu group break, settings band foot. 5. **Paint over black**: ochre smear and black dry-brush stroke (combat commands), Art Deco bronze lattice in corners, red and white petals drifting -> Play hover, title band, empty page.
- **Game element map (11):** combat command stroke + key prompt + ochre smear -> Play button; settings row (arrow notch, `‹ value ›`) -> details rows, settings tree, `ComboBox`; inventory lozenge tabs -> `TabControl` headers and top bar view switches; key prompt box -> menu shortcuts and the More/Edit square buttons; trapezoid bottom buttons (Buy Item / Back) -> `Button`; description card with corner ticks -> metadata pane, tooltips, `GroupBox`; character card (cut top corners, bronze lattice, HP bar, level numeral) -> grid cover selection frame and `ProgressBar`; skill tree diamond node -> `CheckBox`, `RadioButton`, `Slider` thumb, score badge, side-panel close plate; Victory heading with crossing tick rule -> game title and metadata group breaks; Chroma lozenge -> filter active mark and checked menu rows; start screen petals -> empty game page; Lumina cyan item -> running indicator.
- **Signature levers:**
  - Hero banner transition: **dry-brush dissolve**: the banner's foot is eaten by a streaky brush mask (`brush-foot.png` as `OpacityMask`), not a smooth gradient.
  - Play button: **combat command stroke**: a black dry-brush stroke plate (ragged ends) with a key prompt box holding the play triangle, PLAY in Cinzel caps; ochre smear sweeps in under it on hover.
  - Metadata container and group break: **description card** (charcoal-plum card, cream corner ticks) with **hairline + crossing tick** breaks.
  - Chip and score: chips are **lozenge tags** (pointed both ends, chalk rim); scores are **skill nodes** (Oswald numeral in a turned square).
  - Row and cover selection mark: rows take the **plum arrow plate that reaches left** with a brightening rim; covers take the **character card frame** (cream hairline, cut top corners) with a cream node dropping onto the top edge.
  - Side-panel close plate: **skill node diamond** 28x28 (turned square hairline plate with an X), `DangerBrush` fill on hover.
  - Menu: charcoal-plum card with a bronze lattice strip on top and cream corner ticks; highlight = **plum arrow plate whose point slides out left** and whose chalk rim fades in; group break = **hairline with a crossing tick** at the icon column; shortcuts = **key prompt boxes** (hairline rounded squares, cream on highlight); checked = Chroma lozenge; Exit = blood red label, red plate on highlight.
- **Hero moment:** Play hover: the ochre smear wipes in under the stroke from the left (380 ms), the key prompt fills cream with a charcoal triangle, the label turns cream; press sinks the stroke 2px down the slant and darkens the smear.
- **Secondary moments (8):** details row hover (charcoal plate + faint rim) and selection (plum plate reaches 8px left, rim brightens, label to white); cover hover (lift 4px, chalk rim) and selection (cut-corner cream frame draws, node drops); cover buttons (diamond nodes stagger in); sidebar selection (plum lozenge slides in from the rail edge); tree selection (plum arrow plate reaches left); tab (plum fill fades in); checkbox (cream node fills); slider (diamond thumb).
- **Motion:** fast 120 ms, base 200 ms, slow 380 ms; `PowerEase` out (power 3) for entrances, in-out for fades; entrances move in from the left 8px; stagger 60 ms.
- **Brand:** Brushlight (light out of paint, echoing "clair obscur"); mark = a tall lozenge split by a hairline (the Chroma shape) crossed by a short brush stroke, with two small nodes beside it. Used in the settings title band, the empty page and the tile. `GameBannerTintBrush` = `--card`, the plum-black of the character cards.
- **Kept calm:** library lists and the cover grid sit on flat `--void`; lattice only in corners, bands and the empty page; brush textures only on plates and Play.
