Ancient: notices

This is an unofficial fan theme. It is not affiliated with, endorsed by or sponsored by Valve Corporation.
"Dota" and "Dota 2" and related names and marks belong to Valve Corporation; they are mentioned only to say what the
look of this theme takes inspiration from.

No Valve artwork, logos, fonts, sounds or game files are included in this theme or were used to make it. Color values,
sizes and control shapes were read from the game's public interface stylesheets (Panorama CSS, as mirrored in the
SteamDatabase/GameTracking-Dota2 repository) and written out as numbers; no file from the game is shipped. The layout
(a top bar with uppercase tabs and a glow behind the current one, a black secondary strip, bevelled buttons, a green
Play button) was drawn to resemble the game's main menu.

The icons in Media.xaml and the add-on tile icon (source: art/mark.svg in the repository) are original artwork made
for this theme, released under the repository's MIT license (LICENSE).

The theme bundles no fonts. It asks for Radiance and Reaver when they are installed, then Segoe UI and Georgia,
which ship with Windows.

The Playnite Default theme files this theme starts from are MIT licensed: see LICENSE-Playnite.txt.
