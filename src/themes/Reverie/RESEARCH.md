# Reverie: Dreams reference study

Source: [Game UI Database, Dreams (2020)](https://www.gameuidatabase.com/gameData.php?id=170), inspected 2026-11-11. Captures examined: mode selection `Dreams06172020-012223-73842.jpg`, collection `Dreams06172020-011610-21054.jpg`, preferences `Dreams06172020-011614-32367.jpg`, detail `Dreams06172020-011613-9200.jpg`, and menu recording `Dreams06302024-021352-3105.mp4`, all under the database's uploads directory (video under uploads/video).

Observed: deep violet atmospheric space; thin, irregular neon outlines around floating illustrated choices; hot pink Dream Surfing, orange Dream Shaping, cyan secondary choices. Preferences use warm luminous yellow rounded buttons and bead-like sliders over purple haze. Detail pages use a strong color field with light sans serif labels, circular actions and simple tags. The type appears humanist sans; exact font unidentified. Use Segoe UI for readable installed fallback, Segoe UI Semibold headings, no logo reproduction.

Measured from downloaded 1920x1080 JPEG reference: mode background pixels at normalized (.1,.1) #11002C, (.5,.1) #12012E, (.5,.5) #705B94, (.8,.8) #14063B. Preferences (.5,.1) #612970, (.8,.8) #3A0553. JPEG samples include art, not official design tokens. Gold/pink/cyan values are interpretation, not claimed official colors: #FFE29A, #FF71DB, #63E5F2. Text #FFF7EF; quiet text #D0BDDF. Inputs #25113E; raised plum #30174C; subdued rim #705183. Gold primary buttons with dark plum text; pink selection outline; cyan notifications/focus.

Effect proportions observed at 431px-wide browser: neon line about 1-2px and bloom around 5-8px (~4-9px line and 22-36px bloom at 1920). Adapt to desktop controls: 1.5px line, 12px soft bloom. Original generated white alpha assets only: radial bloom 128x128, organic orbit 256x256, cloudy haze 512x256; no game assets shipped. Quiet library surfaces; haze reserved for title bands and empty state.

Motion recording shows floating neon choices, a travelling dotted cursor trail and soft atmospheric movement. Exact durations are not measured; chosen adaptations: 180ms hover fade, 120ms press, 200ms cover controls with 60ms stagger; 3s opacity breathing only in visible empty state. Reduced-motion setting disables decorative loops and movement, keeping brief feedback. No permanently animated library background.

Design: keep Playnite's left rail and search/filter/sort grouping. Hero and library covers carry the imagery. An original asymmetric three-loop orbital doodle identifies the theme in window chrome and empty pages. Settings uses gold selected plates with plum text and a small pink bead; ordinary controls are 32px with 10px radius. No corporate-card grid, no generic mint circuit ornament, no game logos.

Implementation evidence: WPF source via Context7 `/dotnet/wpf`, Fluent.xaml Trigger EnterActions/ExitActions with named opacity targets and SnapshotAndReplace. Playnite Default 10.60 resources and repository API snapshot are the compatibility baseline. Existing overview implementations are references for parts and layout behavior only, never visual assets.

## Revision 2026-11-11: match the My Preferences screen

Captures compared: three My Preferences frames (controls tab with panel and sliders, UI size list, controls tab at 1080p). Sampled from the 1920x1080 frame (JPEG, art included, so values are interpretation): haze #2C045C to #520C71 (page #3B0F63, shell #240549); selected plate #F5E3A9 (cream #F7E4AA); dark plate fill #2F0700 to #521803 (#2E0B06); plate label warm gold about #FFD46A; panel fill about #42104C to #521C54 with a near-white lilac rim (#D9CCEA); slider line #FDE2A3; scroll thumb #AFAFAF on a #45265B track (#B3ADBE, #3A1A57).

Shapes seen: every choice is a capsule (left section list, tab row, option rows); unselected plates are near-black maroon with a thin orange rim that splits into pink and cyan fringes and a soft glow; the selected plate is flat cream with a warm halo and a brown label. Panels are rounded rectangles (about 8px) with a 1px lilac rim; sections divide with a dotted lilac line; sliders are a warm line with bead stops, a cream round thumb with an arrows mark, and round minus/plus ends; check marks sit in cream circles; the scroll bar is a grey pill in a dark track. The title is a heavy rounded cream face with an orange glow over a pink/orange sunburst linework and out-of-focus bokeh discs.

Adaptations: capsules use a 16px radius at the 32px control height (never the 9999 full radius). Letter-spaced uppercase labels and the rounded display face are not reproducible in WPF without a bundled font; Segoe UI Black and Semibold stand in. Backgrounds were kept at the first pass deep violet by request; a seeded bokeh mask was tried under Settings and removed. The sun behind the Settings title reuses the original orbit mask. The slider's minus/plus ends are not drawn: Playnite sliders have no such buttons, bead ends mark the range instead.
