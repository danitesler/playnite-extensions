Uplink: notices

This is an unofficial fan theme. It is not affiliated with, endorsed by or sponsored by Blizzard Entertainment.
"StarCraft" and related names and marks belong to Blizzard Entertainment; they are mentioned only to say what the look
of this theme takes inspiration from.

No Blizzard artwork, logos, fonts, sounds or game files are included in this theme or were used to make it. The colors
are hex values listed in the game's public UI data (its font style constants) or chosen by eye; the layout and motifs
(a top navigation bar with a lit line under the current tab, a sub navigation strip, plates with cut corners, blue glows)
were drawn to resemble the game's menus.

The icons in Images/Icons and in Media.xaml (sources: icons/*.svg and art/icons.py in the repository) and the add-on tile
icon are original artwork made for this theme, released under the repository's MIT license (LICENSE).

Headings use Orbitron (by Matt McInerney), an open font bundled with the theme as a stand-in for Eurostile Extended,
which is not included. Body text uses Segoe UI, which ships with Windows.
The font files and their license (SIL Open Font License 1.1, OFL.txt) are in the theme's Typography folder.

The Playnite Default theme files this theme starts from are MIT licensed: see LICENSE-Playnite.txt.
