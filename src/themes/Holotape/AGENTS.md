# Holotape — theme notes

## What this is

Playnite **Desktop** theme (`ThemeApiVersion` 2.9.0) after the **Fallout 3** (2008) and **Fallout: New Vegas** (2010) interfaces: the Pip-Boy 3000, the RobCo terminals and the menus. Dark only.

The two games are combined, not alternated, and kept quiet:

| From | Holotape keeps | Holotape drops |
|------|----------------|----------------|
| New Vegas | Warm sepia/yellow-brown backdrops (pushed down to near-black surfaces), the amber `#FFB642` for titles and section headers, parchment-tinted body text | Full-screen amber monochrome |
| Fallout 3 | The Pip-Boy green `#1AFF80` as the **only** emphasis: selection, focus, checked marks, Play, progress | Green-on-black everywhere, heavy glow and bloom |
| Both | 1px outlined selection box, header rules with short end ticks, segmented stat bars, the "equipped" filled square, square corners, dimmed unselected rows, faint scanlines | Vault Boy art, curved CRT, flicker, noise, all-caps monospace body text |

**Unofficial fan theme.** No Bethesda or Obsidian assets: the mark (a tape cartridge) and every rule shape are original; icons are Phosphor. Monofonto (the games' UI face) is named first for headings but not shipped. Fallout, Pip-Boy, Vault-Tec and Vault Boy are trademarks of Bethesda Softworks LLC. See `info/NOTICE-Holotape.txt`.

Shared anatomy (file map, shell rules, game page skeleton, metadata pane, build and first-run checks): **`../AGENTS.md`**. Loading rules and build checks: **`docs/themes/reference.md`**.

## Sources

Full source list, what is measured and what is judged: **[`RESEARCH.md`](RESEARCH.md)**. In short:

- Accents are the games' own INI defaults: Fallout 3 green `#1AFF80` (`uHUDColor` / `uPipboyColor`), New Vegas amber `#FFB642` (the same keys); Fallout 3 VATS `#41D2A0` (STEP Modifications default lists).
- Surfaces (`#14110A`, `#1B170E`, `#0C0A06`) are **Holotape's own**: New Vegas's sepia pushed toward black. Nothing was sampled from captures.
- Chrome (outlined selection, tick rules, segmented bars, the equipped square) follows how the Pip-Boy 3000 and terminal screens look; no measurements were taken.
- Fonts: Monofonto (Typodermic) is the games' UI face, named first for headings, not shipped (its license forbids embedding). Fixedsys Excelsior 3.01 is the open terminal stand-in; the in-game terminal font is unverified.
- Icons: Phosphor 2.1.1 light, MIT (`info/LICENSE-phosphor.txt`), generated by `art/phosphor.py`; tile `art/mark.svg` is original.

Body stays proportional on purpose: a monospace description reads as a gimmick within a page.

## Component spacing (`src/Common.xaml`)

Rows 32px (`ButtonPadding` 14,6.5; `InputPadding` 10,6.5); menu and list rows 28 (`MenuItemPadding` 10,4.5,16,4.5); `MenuPadding` 4; `IconSize` 18; focus box 2px outside the control. `GameBannerHeight` 340, `GameDetailsPaneWidth` 300, `GridDetailsPaneWidth` 300.

**Settings chrome.** `DefaultControls/TreeView.xaml`: a RobCo menu, 30px square rows in the body face with a `>` prompt cell; hover is the row fill with the prompt at 45%, selected is the 1px green outline over the green wash with the full green prompt; children under a 1px guide; Settings width 250. `DerivedStyles/StandardWindowStyle.xaml`: 40px terminal status bar, a green `>` before the amber title, a tick ruler (1px tick every 8px, a dashed `Line` in a `Canvas`) above the closing 1px rule; `WindowBarButton` is 40x30, square.

## Game page

Skeleton and metadata pane as in `../AGENTS.md`: Steam screenshots in the left column above the description, banner spacer scaled with `HeroArt` through `MathConverter` (100/340 details, 72/340 grid). Differences: the banner carries the same faint scanlines as the library; the title is amber over a 48 x 2 green mark; section headings are amber at `FontSizeLarge` over the tick rule; the metadata pane is `pb-panel` inside a 1px rule, 18px inside.

Empty state (no game selected): both overviews hide the page and show a RobCo terminal prompt, `> No game selected` (`LOCErrorNoGameSelected`) with a blinking block cursor in a recessed well, faint phosphor flicker, a scanline band rolling down the well every 4s and a tick rule below; loops run only while it shows. The page root is opaque (`ContentBackgroundBrush`) so the banner fades to it with a plain gradient; the banner scanlines are 1px scrim-colored lines drawn on top, not an `OpacityMask`.

## Deviations

- No `OpacityMask` on any art (banner, library), because masked art behind animated controls leaves dark boxes on scaled displays. The library art no longer shows behind the game page.
- No bloom, blur or color tint over images: WPF has no cheap equivalent over live art; the scanlines are the only screen effect.
- Fonts are fallbacks unless Monofonto / Fixedsys Excelsior are installed (not redistributable / not shipped).
- Add-on sidebar icons are 16 x 16 (plate padding), not sized by `IconPadding`: stacking both collapses the icon to 0px.
- DataGrid and the edit dialog are not restyled; they take the palette keys.
- Header rules have a tick at both ends; the Pip-Boy often breaks the line around the active tab label, which Playnite's dynamic tab strips cannot follow.

## Previews

`art/preview-details.html` and `art/preview-settings.html` are 1280x720 HTML replicas drawn from the XAML values and `src/tokens.css` (colors as `var(--pb-*)`), rendered to `art/screenshot-details.png` and `art/screenshot-settings.png` by `.\scripts\take-screenshots.ps1 -Extension holotape`. They are not Playnite captures. Details: rail, top bar in the order of `Views/TopPanel.xaml` (search, icon-only view / view settings / group / sort items, filter, notifications, global progress), game list left of the game page, banner, screenshots and description left, metadata pane right. Settings: Playnite's Settings window with the section tree, three group boxes, and the footer with Save then Cancel.

Signature motifs drawn: (1) the 1px green selection box over the green wash (rail, list row, tree node, shot, chip); (2) amber headings over the tick rule; (3) faint scanlines and a vignette on the banner; (4) the segmented green stat bar (global progress); (5) the "equipped" filled-square check box and the 2px gauge slider with a green needle. The banner scene (a radio tower on mesas) and every game, studio and description are invented; no Bethesda or Obsidian art.

Fonts: headings and monospace text are Cascadia Mono, bundled in `src/Typography/` and named first in the previews; Bahnschrift with Barlow, Bahnschrift SemiCondensed with Barlow Semi Condensed, Segoe UI with Selawik. Real Monofonto differs in letterforms and width.
