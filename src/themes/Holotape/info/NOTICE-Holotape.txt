Holotape

This is an unofficial fan-made theme, inspired by the interfaces of Fallout 3 and Fallout: New Vegas. It is not affiliated with, endorsed by or sponsored by Bethesda Softworks, ZeniMax Media, Obsidian Entertainment or Microsoft.
Fallout, Pip-Boy, Vault-Tec and Vault Boy are trademarks of Bethesda Softworks LLC, a ZeniMax Media company.

The theme contains no files from the games. Its mark (a tape cartridge) and its layout were drawn for this theme; the icons are Phosphor (MIT, LICENSE-phosphor.txt). No Vault Boy or Vault-Tec artwork is used.
The two accent colors are the games' default interface colors as stored in their settings (green #1AFF80 in Fallout 3, amber #FFB642 in New Vegas); the surfaces are this theme's own.

The games' UI font (Monofonto, by Typodermic Fonts) is proprietary and is not included. The theme names it first for headings, so a machine that has it installed uses it; other machines fall back to Bahnschrift and Segoe UI. Fixedsys Excelsior is named first for monospace text if installed; otherwise Consolas.

The XAML files start from Playnite's Default theme (MIT); see LICENSE-Playnite.txt.
