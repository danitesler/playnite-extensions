Cordon

This is an unofficial fan-made theme, inspired by the menus of S.T.A.L.K.E.R.: Shadow of Chernobyl. It is not affiliated with, endorsed by or sponsored by GSC Game World.
S.T.A.L.K.E.R. is a trademark of GSC Game World.

The theme contains no files from the game. Its rust and grain textures are procedural (generated by art/textures.py), its mark and its layout were drawn for this theme, and the icons are Phosphor (MIT, LICENSE-phosphor.txt).
Colors follow the game's interface as it is configured and as it can be observed; the game's textures are not reproduced.

The game's UI fonts (Letterica, Graffiti) are bitmap fonts that belong to GSC Game World and are not included. The theme names them first in its font lists, so a machine that has TrueType conversions installed uses them; other machines fall back to Bahnschrift SemiCondensed, Arial Narrow or Tahoma.

The XAML files start from Playnite's Default theme (MIT); see LICENSE-Playnite.txt.
