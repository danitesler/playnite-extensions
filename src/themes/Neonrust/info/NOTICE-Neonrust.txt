Neonrust — Unofficial Community Theme for Playnite
===================================================

Neonrust is an independent, unofficial fan-made desktop theme inspired by the
visual language of RAGE 2 (Avalanche Studios / id Software / Bethesda Softworks).
It is not affiliated with, endorsed by, or sponsored by ZeniMax Media Inc.,
Bethesda Softworks, id Software, or Avalanche Studios Group. All trademarks
belong to their respective owners.

No official logos, game textures, sound files, or proprietary fonts are included.
All vector marks, menu icons, and procedural surface masks in this package are
original works created for this theme.
