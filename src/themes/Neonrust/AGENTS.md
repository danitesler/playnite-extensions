# Neonrust — theme notes

## What this is

Playnite **Desktop** theme (`ThemeApiVersion` 2.9.0), v0.1.0, dark, in the style of **RAGE 2**'s Ranger Datapad (oxidized petrol-teal ground, Solar Yellow selection, Hot Punk Magenta dry-brush). Unofficial fan theme: no official logos or game assets, not affiliated with Bethesda, id Software or Avalanche (`info/NOTICE-Neonrust.txt`).

Shared anatomy: **`../AGENTS.md`**. Loading rules: **`docs/themes/reference.md`**.

## Sources

[`RESEARCH.md`](RESEARCH.md) (10 Game UI Database captures, measured palette) and [`BRIEF.md`](BRIEF.md) (lens, DNA, levers).

## Tokens (`src/tokens.css`)

| Token | Key | Used for |
|-------|-----|----------|
| `--nr-ground` / `--nr-surface` / `--nr-void` | WindowBackgourndBrush / NormalBrush / InputBackgroundBrush | petrol ladder |
| `--nr-teal` / `--nr-teal-dim` | GlyphBrush / NormalBorderBrush | wireframes, links |
| `--nr-yellow` | SelectedBrush | selection slabs, headings |
| `--nr-magenta` / `--nr-magenta-neon` | PrimaryButtonBackgroundBrush / BeamBrush | Play dry-brush, halos |
| `--nr-feltrite` | RunningIndicatorBrush | running / launching |
| `--nr-crimson` | DangerBrush | Exit, close hover |

Fonts: Chakra Petch (bundled, OFL) for headings; Segoe UI body; Consolas mono. Radius 2px.

## Component spacing (`src/Common.xaml`)

`ControlHeight` 32, `IconSize` 16, `GameBannerHeight` 320, paddings 12,5 / 10,5.

## Shell

| File | What it draws |
|------|---------------|
| `Sidebar.xaml` | 44px petrol rail, Wingstick menu tile (`LocalNeonrustMenuMarkTemplate`: rotor spins 120° on hover, ticks + core flare while open), yellow chamfered active plate, tier pips |
| `TopPanel.xaml` | 50px bar, magenta→yellow→teal lead rule, sort-first icon bar, yellow tab + magenta halo for active switch, magenta diamond filter pip, segmented progress |
| `Library.xaml` | datapad mesh + magenta/teal corner glows, window art under rail |

## Components

Overviews are generated by `art/gen-overviews.mjs` (then breakpoints applied); edit the generator. Menus: `LocalNeonrustMenuBoardTemplate` (magenta dry-brush highlight, Alt+Q crimson). Fields: `LocalNeonrustFieldTemplate`. Running: Feltrite blue sweep + 3 diamonds. Sprites: `art/sprites.py`.

## Previews

Signature motifs: yellow chamfered selection, dry-brush Play with halo, magenta-capped dossier, stepped ticks, Wingstick mark. Stand-ins: Segoe UI → Selawik, Consolas → Cascadia Mono.

## Deviations

Dry-brush bars are masked sprites, not live brush strokes.

## Not verified yet

Live hover/open of the menu mark, popup menus (`MenuRender.ps1`), Settings/Add-ons windows, ThemeModifier edits, Steam loading flows.
