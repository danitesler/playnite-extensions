Hearthside

This is an unofficial fan-made theme, inspired by the interface of Hearthstone. It is not affiliated with, endorsed by or sponsored by Blizzard Entertainment.
Hearthstone and Blizzard Entertainment are trademarks or registered trademarks of Blizzard Entertainment, Inc.

The theme contains no files from the game. Its mark, the medallion, the ornamented dividers, the gem shapes and its layout were drawn for this theme; the icons are Phosphor (MIT, LICENSE-phosphor.txt).
Colors and proportions follow the game's interface as it can be observed; the game's textures are not reproduced.

The game's title font (Belwe, Bitstream) is commercial and is not included. The theme names it first in its font list, so a machine that has it installed uses it; other machines fall back to Bookman Old Style or Georgia. Body text uses Franklin Gothic Medium, which ships with Windows, then Segoe UI.

The XAML files start from Playnite's Default theme (MIT); see LICENSE-Playnite.txt.
