Silver 98 — Unofficial Community Theme Notice

Silver 98 is an original, unofficial Playnite Desktop theme inspired by the classic
3D silver window chrome (#C0C0C0), 2px raised and sunken bevels, #000080 to #1084D0
active title bar gradients, Explorer 4.0 Web View 4-color rules, and 16-color VGA
pixel icons of Microsoft Windows 95 and Windows 98.

This theme is not affiliated with, endorsed by, sponsored by, or associated with
Microsoft Corporation. It contains no official Microsoft logos, trademarks, or
extracted operating system binaries.
