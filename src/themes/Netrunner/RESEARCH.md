# Netrunner — research & sources

## Sources

| What | Where |
|------|-------|
| Main colors | The game's ink style values as quoted by the modding community (CET / ink widget dumps): `MainColors.Red` (1.176, 0.381, 0.348 linear HDR → `#FF6158` clamped), `MainColors.Blue` (0.369, 0.965, 1.0 → `#5EF6FF`), `MainColors.DarkRed` (`#52272A`). Recalled, **not re-verified against a dump in this session.** |
| Surfaces, sizes, layout | Judged from 1080p captures of the pause menu, inventory, journal and settings screens. Surfaces (`#0B0B12`, `#16161F`) are estimates of the blue-black under the scanline haze. |
| Brand yellow | `#FCEE0A`, the common published value for the game's key-art yellow. |
| Fonts | Rajdhani (Indian Type Foundry, OFL) is widely identified as the menu face; Bahnschrift is the Windows fallback (squared DIN). |
| Icons | Phosphor 2.1.1 regular, MIT (`info/LICENSE-phosphor.txt`), generated by `art/phosphor.py` (PNG menu icons in the menu red, exit/remove in the alarm red, the star in yellow) |
| Add-on tile | `art/mark.svg`, original: a cut-corner plate with a chip cut out |
