Netrunner

This is an unofficial fan-made theme, inspired by the menus of Cyberpunk 2077. It is not affiliated with, endorsed by or sponsored by CD PROJEKT RED or CD PROJEKT S.A.
Cyberpunk and Cyberpunk 2077 are trademarks of CD PROJEKT S.A. Cyberpunk is a registered trademark of R. Talsorian Games.

The theme contains no files from the game. Its mark and layout were drawn for this theme; the icons are Phosphor (MIT, LICENSE-phosphor.txt).
Colors and proportions follow the game's interface as it can be observed; the game's textures, glitch effects and logos are not reproduced.

The game's menu face, Rajdhani, is a free font (SIL Open Font License, Indian Type Foundry) and is not bundled. The theme names it first in its font lists, so a machine that has it installed uses it; other machines fall back to Bahnschrift or Segoe UI.

The XAML files start from Playnite's Default theme (MIT); see LICENSE-Playnite.txt.
