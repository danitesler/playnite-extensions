Frontier

This is an unofficial fan-made theme, inspired by the menus of Red Dead Redemption 2. It is not affiliated with, endorsed by or sponsored by Rockstar Games or Take-Two Interactive.
Red Dead Redemption and Red Dead Redemption 2 are trademarks of Rockstar Games.

The theme contains no files from the game. Its mark, the rail's ragged edge and its layout were drawn for this theme; the icons are Phosphor (MIT, LICENSE-phosphor.txt).
Colors and proportions follow the game's interface as it can be observed; the game's textures are not reproduced.

The game's UI fonts (RDR Lino, Hapna Slab Serif) are proprietary and are not included. The theme names them first in its font lists, so a machine that has them installed uses them; other machines fall back to Zilla Slab, Roboto Slab, Rockwell or Georgia.

The XAML files start from Playnite's Default theme (MIT); see LICENSE-Playnite.txt.
