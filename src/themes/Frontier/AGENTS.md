# Frontier — theme notes

## What this is

Playnite **Desktop** theme (`ThemeApiVersion` 2.9.0) inspired by the menus of **Red Dead Redemption 2**: near-black pages, flat dark list rows, white type, the red painted pause panel as the rail, and the red selection frame around whatever is selected. Square corners, no gradients except the tapered rules.

**Unofficial fan theme.** No Rockstar assets: every glyph, mark and the rail's ragged edge is original or from an open icon set. The game's fonts (RDR Lino, Hapna Slab Serif) are not shipped; the theme names them first and falls back to Zilla Slab / Roboto Slab / Rockwell / Georgia. Rockstar, Red Dead Redemption and Red Dead Redemption 2 are trademarks of Rockstar Games.

Shared anatomy (file map, shell rules, game page skeleton, metadata pane, build and first-run checks): **`../AGENTS.md`**. Loading rules and build checks: **`.claude/skills/playnite-theme-dev/reference.md`**.

## Tokens (`src/tokens.css`)

| Token | Key | Used for |
|-------|-----|----------|
| `rdr-page` 080808 | `WindowBackgourndBrush`, `ContentBackgroundBrush`, `TopPanelBackgroundBrush`, `NormalBrushDark` | Sub-screen background |
| `rdr-row` 1c1c1c | `ButtonBackgroundBrush`, `InputBackgroundBrush`, `NormalBrush` | List row |
| `rdr-row-hover` 282828 | `HoverBrush`, hover keys | Hovered row |
| `rdr-red` c00000 | `ShellBackgroundBrush`, `PrimaryButtonBackgroundBrush`, `DangerBrush` | Pause panel, Play |
| `rdr-red-frame` d80419 | `GlyphBrush`, `SelectedBrush`, `FocusBrush`, `TabItemIndicatorBrush` | Selection frame and the short underline |
| `rdr-text` / `-dim` / `-ink` | `TextBrush` / `TextBrushDarker` / `TextBrushDark` | White type, dim grey, black ink on the red panel |
| `rdr-panel` 0d0d0d, `rdr-edge` 2d2d2d | popup keys | Inkroller side panel (black at 90% flattened) |
| `rdr-gold` | `DataChangeNotifBrush` | The star on special items |

Radii are all 0, so the repo rule against `CornerRadiusFull` on non-square controls holds by construction (no pill, no oval tracks); `CornerRadiusFull` stays defined as 0 for plugins that read it. `FrameThickness` is 3 (4px at 1080p scaled by 2/3).

## Component spacing (`src/Common.xaml`)

Rows 50px with a 4px gap at 1080p scale to 34 and 3 here (`ButtonPadding` 16,7.5; `InputPadding` 8,7.5); menu rows 30 tall; sub-screen margins 98px become 64px; `IconSize` 18.

## Shell

| File | What it draws |
|------|---------------|
| `Views/Sidebar.xaml`, `CustomControls/SidebarItem.xaml` | 44px compact red panel on the left (44 x 40 items, 16px glyphs) with an original ragged brush edge (10px overlay path, no layout width); black glyphs, white for the current item with a 2px underline |
| `Views/TopPanel.xaml`, `CustomControls/TopPanelItem.xaml` | 56px bar on the page color ending in a 2px rule that fades at both ends; search row, dim glyph hints with a red underline on the active one |
| `DerivedStyles/MainWindowStyle.xaml` | 44 x 32 square window buttons, close hovers red |
| `Views/Library.xaml` | Library art darkened and vignetted like the pause menu background |
| `Views/FilterPanelView.xaml`, `Views/ExplorerPanel.xaml` | Store-style side panels |

## Game page

Skeleton and metadata pane as in `../AGENTS.md`: Steam screenshots in the left column above the description, banner spacer scaled with `HeroArt` through `MathConverter` (100/340 details, 72/340 grid). Differences: sections are titles over a short red underline with no box; the metadata pane is the game's image-box grey (`ExpanderBackgroundBrush`), square, 20px inside; the title carries the red underline; Play is the red slab.

## Components

| Playnite file | RDR2 element |
|---------------|--------------|
| Button, ToggleButton, TextBox, ComboBox, ListBox | Settings list row; hover and focus draw the red frame inside the row |
| CheckBox, RadioButton | White outlined tick box and ring |
| Slider | 8px rail, white fill, a 4px tick as thumb (the game has none) |
| ProgressBar | Compendium 8px white bar |
| Menu, ContextMenu, ToolTip | Inkroller side panel |
| TabControl | Store sub-tab line (title face, red underline) |
| GroupBox | Section title over a tapered rule |
| GridViewItem* | Help / Progress tiles with the red frame when selected |

## Deviations

- No dry-brush texture or torn edges except the rail's ragged edge; WPF has no cheap equivalent.
- Library art keeps its color (the game desaturates and blurs it).
- The game shows selection by frame only; the sidebar also underlines the current item for contrast.
- Fonts are fallbacks unless the game's fonts are installed.
