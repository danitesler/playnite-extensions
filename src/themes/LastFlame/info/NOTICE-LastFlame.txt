Last Flame

This is an unofficial fan-made theme, inspired by the interface of Darkest Dungeon II. It is not affiliated with, endorsed by or sponsored by Red Hook Studios.
Darkest Dungeon is a trademark of Red Hook Studios Inc.

The theme contains no files from the game. Its mark, icons, frames, ribbons, pennant, brazier, grain and ember sprites were drawn or generated for this theme. Its colors follow the game's interface as it can be observed in public screenshots; the game's art, icons and logo are not reproduced.

The theme names Dwarven Axe BB first in its heading font list, so a machine that has it installed uses it; no font is included. Other machines fall back to Georgia.

The XAML files start from Playnite's Default theme (MIT); see LICENSE-Playnite.txt.
