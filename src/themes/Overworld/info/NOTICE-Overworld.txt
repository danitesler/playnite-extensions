Overworld: notices

This is an unofficial fan theme. It is not affiliated with, endorsed by or sponsored by Mojang Studios or Microsoft.
"Minecraft" and related names and marks belong to Mojang Synergies AB / Microsoft; they are mentioned only to say what
the look of this theme takes inspiration from.

No Mojang artwork, logos, fonts, sounds, textures or game files are included in this theme. Color values, sizes and
control shapes were read from the game's interface sprites and client code and written out as numbers; no file from the
game is shipped. The layout (stone buttons with a white outline when highlighted, black text fields, a dark tab strip,
outlined list selection, purple-edged tooltips, a yellow splash text, a green Play button) was drawn to resemble the
game's title screen and menus.

The pixel icons are Pixelarticons 2.4.1 (MIT License): see LICENSE-pixelarticons.txt. The add-on tile icon
(art/mark.svg) is original artwork made for this theme, released under the repository's MIT license (LICENSE).

Buttons, tabs and titles use Pixelify Sans (by Stefie Justprince), an open pixel font bundled with the theme; body text
uses Segoe UI, which ships with Windows. The game's own fonts are not included.
The font files and their license (SIL Open Font License 1.1, OFL.txt) are in the theme's Typography folder.

The Playnite Default theme files this theme starts from are MIT licensed: see LICENSE-Playnite.txt.
