# Playnite Extensions

Free, open-source **Playnite** add-ons: small plugins that tidy up the desktop library and **desktop themes**. Each add-on is built and published on its own; pick the ones you want.

I'm a product designer, and these are what I make when I'm not doing that. They're free and will stay free. If they make your library nicer, the best support is a suggestion or bug report on the [issues page](https://github.com/danitesler/playnite-extensions/issues). If you like my work and want to see more, take a look at my [portfolio](https://danitesler.com), or [buy me a coffee on Ko-fi](https://ko-fi.com/danitesler) if you'd like to chip in. Thank you 🙂

## Add-ons

Each add-on has its own page (**Details**: overview, screenshots, install steps) and its own **GitHub Release** and installer (`.pext` for extensions, `.pthm` for themes, **Download**). You can also browse **[Releases](https://github.com/danitesler/playnite-extensions/releases)**, open the release for the add-on you want, and download the attached file. You can also find and install them from **Add-ons** inside Playnite.

## Installation

1. **Inside Playnite:** open **Add-ons** from the main menu, browse or search for the extension, and install it from there.
2. **Or from GitHub:** on **[Releases](https://github.com/danitesler/playnite-extensions/releases)**, open the release for the add-on you want, download its `.pext` or `.pthm` file, and open it in **Windows** (double-click or choose **Open**).
3. Click **Install** when Playnite prompts you, then restart Playnite.
